# Physical tram axes and delivery profile

`osm-tracks.json` is a source publication of the OpenStreetMap-derived track database used by this profile. Copyright OpenStreetMap contributors; available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). See [OpenStreetMap's copyright and license notice](https://www.openstreetmap.org/copyright). The extract keeps the original mapped node coordinates, way node order and way tags. Contributor account fields and unrelated elements are excluded.

`source-ledger.json` pins the acquisition and derived extract, records the original procedural rail artwork's CC0 license, and identifies reference-only Street View and HSL observations. No Google or HSL image pixels are distributed. The HSL map is the version effective 31 August through 31 December 2026. It is a network reference, while the licensed OSM axes author exact placement.

`profile.json` selects physical surface tram ways intersecting the existing playable area, keeps the earlier Mannerheimintie ways as context, and records every exclusion. Five accepted source ways have small uncovered junction ribbon fragments; they are explicit `uncovered-existing-ribbon` repair targets rather than duplicate mainline tracks. Complete original ways remain in the extract even where rendering is clipped at the playable boundary. The profile does not claim current passenger service on every physical track.

Run `tools/world/prepare_delivery_tram_profile.ts` against the exact source snapshot, acquisition ledger, accepted previous profiles, gameplay scope and delivery manifest to regenerate the three JSON files. Repeat `--existing-tail-way` for each ID in `profile.json`'s `existingTailWayIds` to reproduce the accepted ribbon repair targets. Run `tools/world/apply_delivery_tram_visuals.ts` against that manifest and profile to create fresh patch payloads. Every repair target is cut against the actual decoded old rail mask before support or emission; a whole accepted way ID is not assumed to mean every part was delivered. The adapter refuses an incorrect baseline, an altered source axis, unsupported rail fragments, an unqualified bridge deck, duplicate old rail footprints, or an exceeded geometry/draw/memory budget. A blocked plan is diagnostic evidence and cannot create `patches.json`.

New rails use the original 1,000 mm gauge and grooved steel cross section. They drape on measured matching rendered and collision floors with a nominal 3 mm lift and at most 0.1 mm Float32 construction error, while preserving existing compressed geometry and image bytes. Tier equivalence compares the recorded source-floor planes within 10 µm; byte-identical LOD1 source payloads share the already paired LOD0 floor proof. Old Mannerheimintie rails retain ownership at crossings. Coarse tiers reuse an existing vertex-color primitive and add no draw calls. Any required support repair is a separately bounded, independently verified ground and collision derivative made before this visual-only adapter runs.
