# Game and character workflow skills

These self-contained skill folders include instructions, reference notes, scripts,
and templates for game and character production:

| Skill | Purpose |
| --- | --- |
| [build-helsinki-game](build-helsinki-game/SKILL.md) | Helsinki browser-game planning, geodata preparation, Blender assets, and verification. |
| [motion-design](motion-design/SKILL.md) | Character locomotion generation, retargeting, skin checks, GLB export, and runtime blending. |
| [texture-mapping-3d](texture-mapping-3d/SKILL.md) | Apply reference-image colours and textures to an existing rigged character. |

## Installation

Copy each desired skill directory, including all its supporting files, into
your agent's documented skill installation directory. The examples below use
`.agents/skills/`; adjust command paths to match your installation.
Read the selected skill's setup instructions before running its helpers.

Blender, Python packages, model downloads, and optional external services are
separate prerequisites. The repository does not include model weights, source
characters, credentials, generated runs, or local logs. Keep those outputs outside
the installed skill folders.
